# POPCORN

Version: 0.02v

POPCORN is a lightweight web application for sharing and managing creative projects.

## Project structure

- frontend/ - static web pages and client-side scripts
- server/ - backend Python application and data files

## Basic usage

1. Install dependencies:
   python -m pip install -r server/requirements.txt
2. Start the application:
   python server/main.py
3. Open the frontend in a browser from the frontend folder.

## Notes

This release focuses on the basic project structure only. Experiment Mode, moderation, and chat are intentionally not included.
